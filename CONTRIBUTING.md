# Contributing

Thank you for improving Grounded Roundtable.

Good first contributions include:

- natural-language rules that remove translationese without strengthening a claim;
- new discussion directions with clear scene rhythms;
- manifest and native-player validation cases;
- accessible dark slide themes;
- fixes for Google Slides import behavior.

Before opening a pull request:

1. Keep the virtual-roundtable disclosure visible.
2. Do not add unverified timestamps or fabricated direct quotations.
3. Run the manifest validator on any example you change.
4. Add a small failing fixture when changing a validator.
5. Explain any token-cost increase in the pull request.

Please avoid committing transcripts, generated decks, personal paths, credentials, or copyrighted media.
